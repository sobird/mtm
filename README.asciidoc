# 开源电商运营后台
:toc:

基于 Turborepo 的电商运营后台 monorepo，包含商家后台、运营端（均为 Next.js）以及运营端 API（Hono），并共享权限码、认证与 UI 组件包。

## 技术栈

* Bun workspaces + Turborepo
* Next.js 15（App Router、Route Handlers、Server Components）+ React 19
* Hono + Zod（`apps/core-api`）
* PostgreSQL + Prisma（一个实例、独立数据库）
* Auth.js v5（Credentials 登录，两个门户独立 Cookie 与会话）
* TanStack Query、Zustand
* React Hook Form + Zod、Base UI（Dialog/Toast/Select 等）
* Ant Design（仅限 `components/ui` 封装层内部实现，业务页面只从 `@/components/ui` 导入）、Recharts
* Vitest + Testing Library、oxlint / oxfmt

## 目录结构

apps/ops-admin/        # 运营端（Next.js，端口 3001）

packages/config/       # 共享 lint / format / tsconfig
scripts/               # 仓库级脚本（dev bootstrap 等）
----

## 环境要求

* Bun 1.4.4（由 `packageManager` 字段固定；可用 `.bun-version` 配合版本管理器）
* Docker（`bun run dev` 会通过 Docker Compose 启动本地 PostgreSQL）
* Node.js 22

## 快速开始

[source,bash]
----
cp .env.example .env
bun install
bun run dev
----

`bun run dev` 会依次启动 PostgreSQL、创建所需数据库、执行 Prisma generate / migrate / seed，然后同时启动三个应用：

* 商家后台：http://localhost:3000
* 运营端：http://localhost:3001
* 运营端 API：http://localhost:4000（健康检查 `/health`）

## 权限模型

* 权限码集中定义在 `packages/contracts`，商家端与运营端共用同一套命名（如 `merchant:view`、`product:audit`）。
* 菜单按当前账号的权限快照过滤，无权限的菜单项不渲染。
* 页面进入前由服务端守卫校验权限，权限不足时跳转 `/403`。
* 页面调用的业务接口（`/api/*`）同样按权限码校验；商家端子账号的数据按商家隔离，不信任请求参数。
* 两个门户通过 BFF 调用 `apps/core-api`：先签发 60 秒有效期、带门户与权限声明的签名 JWT，`core-api` 校验签名与权限码后再处理请求。

## 环境变量

参考 `.env.example`。三个业务库分别使用 `MERCHANT_DATABASE_URL`、`CORE_DATABASE_URL`、`OPS_DATABASE_URL`，测试库使用 `MERCHANT_TEST_DATABASE_URL`、`CORE_TEST_DATABASE_URL`、`OPS_TEST_DATABASE_URL`。

两个门户使用独立的会话密钥：商家端 `AUTH_SECRET`、运营端 `OPS_AUTH_SECRET`。门户与 `core-api` 之间的服务间鉴权使用 `CORE_API_JWT_SECRET`（两个门户与 `core-api` 必须配置为同一个值），`CORE_API_URL` 指向 `core-api` 的基地址。

图片上传相关变量：

* `CORE_PUBLIC_URL`：`core-api` 对外基址（默认 `http://localhost:4000`），用于拼接上传文件的绝对 URL。
* `UPLOAD_DIR`：本地图片存储目录（默认 `var/uploads`，相对 `apps/core-api`）。
* `UPLOAD_MAX_BYTES`：单文件上限，默认 `10485760`（10MB）。

开发环境的连接串指向 Docker Compose 启动的本地 PostgreSQL。生产环境必须设置随机的 `AUTH_SECRET`、`OPS_AUTH_SECRET` 和 `CORE_API_JWT_SECRET`，替换所有 `change-me*` 占位值；`NODE_ENV=production` 时缺失或使用占位密钥会导致鉴权失败（运营端启动时直接报错）。同时必须修改上面的演示账号密码。

## 图片上传

品牌图片通过运营端 BFF 上传到 `apps/core-api`，由本地 `StorageAdapter` 写入 `UPLOAD_DIR`：

* 只接受 PNG / JPEG / WEBP，默认上限 10MB（`UPLOAD_MAX_BYTES`）。
* 返回的公开地址形如 `+${CORE_PUBLIC_URL}/uploads/<随机文件名>+`，可直接在浏览器打开。
* `apps/core-api/var/` 已在 `.gitignore` 中，上传文件不提交到仓库；生产环境应替换为对象存储适配器。

## 数据库与种子数据

`bun run dev` 和 `bun run db:reset` 通过 Prisma 迁移建表，并写入 `apps/*/prisma/seed.ts` 中的种子数据；重复执行不会产生重复记录。
