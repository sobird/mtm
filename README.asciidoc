# 开源电商运营后台
:toc:

基于 Turborepo 的电商运营后台 monorepo，包含商家后台（Next.js）、运营端 API（Hono）以及共享配置。

## 技术栈

* Bun workspaces + Turborepo
* Next.js 15（App Router、Route Handlers、Server Components）+ React 19
* Hono + Zod（`apps/core-api`）
* PostgreSQL + Prisma（一个实例、独立数据库）
* Auth.js v5（Credentials 登录）
* TanStack Query、Zustand
* React Hook Form + Zod、Base UI（Dialog/Toast/Select 等）
* Ant Design（仅限 `components/ui` 封装层内部实现，业务页面只从 `@/components/ui` 导入）、Recharts
* Vitest + Testing Library、oxlint / oxfmt

## 目录结构

[source,text]
----
apps/merchant-admin/   # 商家后台（Next.js，端口 3000）
apps/core-api/         # 运营端 API（Hono，端口 4000）
packages/config/       # 共享 lint / format / tsconfig
scripts/               # 仓库级脚本（dev bootstrap 等）
----

## 环境要求

* Bun 1.4.4（由 `packageManager` 字段固定；可用 `.bun-version` 配合版本管理器）
* Docker（`bun run dev` 会通过 Docker Compose 启动本地 PostgreSQL）
* Node.js 22

## 快速开始

[source,bash]
----
cp .env.example .env
bun install
bun run dev
----

`bun run dev` 会依次启动 PostgreSQL、创建所需数据库、执行 Prisma generate / migrate / seed，然后同时启动两个应用：

* 商家后台：http://localhost:3000
* 运营端 API：http://localhost:4000（健康检查 `/health`）

演示账号手机号为 `13412345678`，验证码使用登录页上显示的图形验证码。

## 常用命令

[source,bash]
----
bun install        # 安装依赖
bun run dev        # 启动 PostgreSQL、迁移、种子数据并运行所有应用
bun run db:migrate # 应用数据库迁移
bun run db:seed    # 写入种子数据
bun run db:reset   # 重置两个数据库并重新迁移、写入种子数据
bun run build      # 构建所有应用
bun run test       # 运行所有测试（Vitest）
bun run lint       # oxlint
bun run typecheck  # tsc --noEmit
bun run fmt        # oxfmt 格式化
bun run fmt:check  # 格式检查
----

## 环境变量

参考 `.env.example`。三个业务库分别使用 `MERCHANT_DATABASE_URL`、`CORE_DATABASE_URL`、`OPS_DATABASE_URL`，测试库使用 `MERCHANT_TEST_DATABASE_URL`、`CORE_TEST_DATABASE_URL`。开发环境的连接串指向 Docker Compose 启动的本地 PostgreSQL。生产环境必须提供随机的 `AUTH_SECRET`。

## 数据库与种子数据

`bun run dev` 和 `bun run db:reset` 通过 Prisma 迁移建表，并写入 `apps/*/prisma/seed.ts` 中的种子数据；重复执行不会产生重复记录。
